# Política de Privacidade — CinelogPlay

## 1. Coleta de Dados

O CinelogPlay coleta os seguintes dados pessoais:

- Nome
- Email
- Mensagem (via formulário de contato)

## 2. Base Legal

A coleta é baseada no **consentimento explícito** do usuário através do formulário.

## 3. Uso dos Dados

Os dados coletados são usados **APENAS** para:

- Responder a mensagens de contato
- Comunicação com o usuário

Os dados NÃO são:

- Compartilhados com terceiros
- Vendidos
- Usados para marketing

## 4. Retenção

Os dados são mantidos por **30 dias** após o contato.
Após isso, são **automaticamente deletados**.

## 5. Direitos do Usuário (LGPD)

O usuário tem direito a:

- **Acessar** seus dados: `/api/dados/<email>`
- **Deletar** seus dados: `DELETE /api/dados/<email>`
- **Solicitar** exportação dos dados

## 6. Contato

Para exercer direitos: contato@cinelogplay.com
